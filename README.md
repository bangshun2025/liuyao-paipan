# 生命算法 · 六爻排盘

测事体系的排盘与分析工具。依据《六爻测事体系：从公理到实操的完整知识框架》v2.1 实现。

**摇卦取卦（唯一方式） · 京房纳甲 · 卦宫定六亲 · 八步断事流程 + 四层判断框架 + 应期九法。**

当前版本 v0.1.33 · 断言 732 条全绿。

---

## 快速开始

在 Clacky 里打开「生命排盘」，点第 7 张卡片**六爻排盘**；或直链：

```
http://127.0.0.1:7070/api/ext/liuyao-paipan/standalone
```

用法四步：

1. 填「所问之事」（一卦一问）、「事项类型」（定用神）与「所求」（求进·推进 / 求稳·守成 / 求退·收尾，定问卦重心）。
2. 摇卦：自下而上摇六次，每次三枚铜钱，把结果录进六行（三正/二正一反/二反一正/三反）。动爻数由摇得 —— 可能没有，可能一个，也可能多个。手边没有铜钱时，可用**页面代掷**：三枚钱各掷一次、六次独立（摇一次 / 连摇六次），与手上摇等价。
3. 读盘：盘面 6 行 + 19 节分析；点任一行可改用神，底部可复制全盘文本。
4. 存档：排盘后「存入档案」，回访时查看重放、回填验证结果（应验/部分应验/不应验 + 实际应期），案例库自校验。

## 界面说明

- **盘面**：六神 | 伏神 | 本卦 | 变卦，自上爻排至初爻；世/应、动/静、暗动、月破、**日空/月空**、入墓、虚实真假、合起合绊均带标签。
- **变卦**：完整变卦六爻全列（未动之爻浅色随变卦纳甲列出，动爻与静变爻标化进/化退/回头生克，土行化进退带「参考」注）。
- **爻级四标**：每爻格下小字「月X · 卦X · 半X · 爻X日」—— 月建旺衰、整卦旺衰、半卦旺衰、与日令生克比。
- **摇卦记要**：盘面顶部标出本次摇得几个动爻（0 个即六爻全静、无变爻）。六爻皆由代掷得来时，记要写作「摇卦（页面代掷）」；手动改过任何一爻即回到「摇卦」。
- **分析 19 节**：整卦分析（本变五型） → 半卦分析（上/下分组，本→变对照，标我／事随世） → 卦宫与宫位 → 用神（两现取用六环） → 八步流程（应期九法：用神候选 + 世/忌/原神参照） → 四层框架 → 六亲生态 → 转太极 → 飞伏（出伏六条件）。
- **两种参照**：「旺衰参照」可切换年/月/日/时，决定十二长生的比对对象（默认月建）。
- **预测档案**：localStorage 本机存储；导出/导入 JSON 搬运换设备（按 id 去重合并）。查看档案用当前引擎重放——档案永远与最新引擎同步。

## 它不做什么

**不下吉凶断语。** 生克中性（A5）——同一组卦象，问「该不该做」和问「会顺利吗」，结论可以相反。
本工具只把**客观事实链路**摆全：伏神、暗动、月破、虚实真假、本变五型、转太极 —— 判断留给你。

**不用非摇卦的方式取卦。** 时间起卦、报数起卦二式已下线：二者以时刻或两数反推，恒定只得一个动爻，
与「事情的变化可有无、可多少」的事实不符（见 `docs/ADR_六爻.md` D7）。

**所求不改变应期。** 所求只是问卦重心的意图倾向（D12）；应期只按卦例机制推断（九法）。

**月空只标注、不进判定。** v0.1.33 起月柱旬空与日空并列标注；判定层（真空假空/暗动/出空应期）
一切空亡口径仍走日空（D13；Q6 已销案＝D16，2026-10-05）。
