## 1. 干支历法与四柱

复用八字/奇门同源口径，保证跨术数一致。

| 项 | 口径 |
|---|---|
| 年柱 | 立春分界（`yearGz(y-1)` 当摇卦时刻早于当年立春） |
| 月柱 | 按当前**节气**取月支（`JQ_MDZ`：立春→寅），月干以年干起五虎遁 |
| 日柱 | JDN 直算，`dayIdx = (jd(y,m,d)+49)%60`；**子时换日**：真太阳时 h≥23 取次日 |
| 时柱 | 时支 = 时辰序（23:00–00:59 为子）；时干以日干起五鼠遁 |
| 日旬空 | 日柱所在旬：旬首 `floor(di/10)*10`，空亡支 = `DZ[(旬首+10)%12]`、`DZ[(旬首+11)%12]` |
| 月旬空 | 月柱所在旬，同构算法（`mkong`，v0.1.33）——与日空并列双标（§19） |

节气表为 sxtwl 1000–2100 精确表（精确到分），与八字排盘、奇门排盘同源。

**六爻不用通根、不用藏干**（依据 §3.14）：爻的五行直接由纳甲地支决定，强弱只看日辰与
其他爻的生克。

## 4. 六亲：以卦宫五行为唯一基准

**关键口径（不可动摇）**：装卦时六亲的太极点是**本卦所属卦宫的五行**，不是世爻、不是日干。

| 关系 | 六亲 |
|---|---|
| 与卦宫五行同类 | 兄弟 |
| 卦宫五行所生 | 子孙 |
| 生卦宫五行 | 父母 |
| 卦宫五行所克 | 妻财 |
| 克卦宫五行 | 官鬼 |

**变卦六亲仍以本卦卦宫定**（依据 §定义层）：变爻的身份用本卦卦宫判定，
变爻的五行能量取变化后的新地支五行 —— 身份与能量可以不一致。

> ⚠️ 待裁：v2.1 §3.8「天风姤找伏神」案例以**日干甲木**为六亲基准（得「兄弟不上卦、伏神寅木兄弟」），
> 与本文件 §4 及 v2.1 定义层明文「以卦宫五行定六亲」相冲突。本实现按**明文规则**：
> 姤属乾宫（金）→ 父母丑戌、子孙亥、兄弟申酉、官鬼午、**妻财不上卦**，伏神取乾为天二爻甲寅木·妻财。
> 详见 `ADR_六爻.md` D3。

## 6. 飞伏（六亲不上卦）

六爻仅六位、纳支五行未必齐五亲，故有六亲不上卦。

- **飞神**：本卦该爻位实际出现的六亲（明面角色）
- **伏神**：本宫**首卦**（八纯卦）同一爻位上的六亲（隐性角色）

实现：对每种在本卦中**未出现**的六亲，回本宫首卦找其爻位，在该爻位下挂伏神。

飞伏关系判定（客观描述）：

| 关系 | 表现 |
|---|---|
| 飞生伏 | 伏神受养，可出 |
| 飞克伏 | 伏神被压，难出 |
| 伏克飞 | 伏神有力，可挣脱 |
| 伏生飞 | 伏神能量被吸 |

伏神出伏条件：冲飞神、值伏神地支、月日生扶伏神。

## 7. 状态层（旺衰 / 强弱 分离）

依据 §3.3：**旺衰看时令，强弱看局面**，两者独立。

### 7.1 旺衰（十二长生，12 级精度）

爻的旺衰 = 以**爻支五行**为我的「生」，对**参照支**取十二长生状态（长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养）。

> **土分阴阳（v0.1.78，邦顺裁决，撤 v0.1.57 水土同宫）**：阳土（艮宫、辰戌爻）走戊线——长生在**午**顺行（未沐浴、申冠带、酉临官、戌帝旺……巳养）；阴土（坤宫、丑未爻）走己线——长生在**巳**逆行（辰沐浴、卯冠带、寅临官、丑帝旺……午养）。主体为支时按支（辰戌阳、丑未阴），主体为宫／卦时按宫名卦名（艮阳、坤阴），由 `tuYin()` 统一判定。金水木火照旧以五行取阳干顺行（取阳干的理由：六爻为纯地支体系，爻无独立天干身份可言；沿用本体系奇门排盘的既有约定，保证跨术数一致。详见 `ADR_六爻.md` D4）。

### 7.2 时间参照匹配（§3.4）

旺衰参照支由**问题的时间颗粒度**决定，默认月建，可切换：

| 问题尺度 | 参照 |
|---|---|
| 年事 | 年支（太岁） |
| 月事 | 月支（月建）——默认 |
| 今日事 | 日支（日令） |
| 时辰事 | 时支 |

### 7.3 强弱

强弱 = **日令 + 其他爻（仅动爻）** 对该爻的生克合力。

| 作用 | 计权 |
|---|---|
| 生我（得生） | **+1** |
| 同类比和 | **+1** |
| 我生（被泄） | −1 |
| 我克（被耗） | −1 |
| 克我（被克） | **−2** |

合计为「净额」。日令参与同等计权；静爻与静爻之间不参与（§3.6）。

净额 → 标签：≥2 强 / 1 偏强 / 0 平 / −1 偏弱 / ≤−2 弱。

> 克我按 −2 计（其余 −1）：克是直接夺气，比泄、耗更具决定性 —— 这一处是本体系对传统
> 计权方式的显式化，便于读者核对某爻为何被判为「弱」。详见 `ADR_六爻.md` D6。

### 7.4 动静与日冲（§3.6）

| 状态 | 判据 | 能否主动发力 |
|---|---|---|
| 动爻 | 老阴(6)/老阳(9) | 可 |
| 静爻 | 少阴(8)/少阳(7) | 不可（仅被动） |
| 日冲 | 静爻被**日辰**冲（单维，v0.2.20 起不分旺衰生扶一律标） | 不可（纯标志，不参与强弱／真假／虚实） |
| 月冲 | 静爻被**月建**冲 | 中性标注（v0.2.18 撤「月破」称），本体系 §3.6 视月建冲亦为激活 — 待裁项 D5 |

> **冲向术语（v0.2.18，v0.2.20 修订）**：「日冲」＝被日令冲（日辰冲静爻一律标，v0.2.20 起撤暗动／半动半破复合三级，旺衰生扶属综合判断排盘暂不做）；「冲日」＝爻冲日令（爻支冲日辰，动爻标「冲日」）；「月冲」＝被月令冲（中性，v0.2.18 起撤「月破」称）；「冲月」＝爻冲月令（爻支冲月建，动爻标「冲月」）。

### 7.5 空亡 / 入墓 / 合冲

- **空亡**：爻支落在日柱旬空两支内（日空）；v0.1.33 起月柱旬空（月空）同标，双空独立各标（§19）
- **入墓**：爻支五行之墓（木未、火戌、土辰、金丑、水辰）与月支或日支相同
- **六冲**：子午、丑未、寅申、卯酉、辰戌、巳亥
- **六合**：子丑、寅亥、卯戌、辰酉、巳申、午未
- **三合局**：申子辰水、寅午戌火、亥卯未木、巳酉丑金

## 8. 变卦与变化关系

- 变爻 = 动爻变阴阳后所在爻位的**变卦纳支**（纳甲同 §2.2 按变卦上下卦取）
- 变爻六亲 = 以**本卦卦宫**定（§4）
- 变卦按**完整六爻**呈现（`g.bian.yao[6]`）：未动之爻也随变卦纳甲列出（同一卦的下卦或上卦
  一变，该卦三爻的纳支全变），变卦六亲同样一律以本卦卦宫五行定；界面未动之爻以浅色显示

| 关系 | 判据 |
|---|---|
| 回头生 | 变爻五行生本爻五行 |
| 回头克 | 变爻五行克本爻五行 |
| 比和 | 五行相同 |
| 化进 | 同五行且地支顺进（亥→子、寅→卯、巳→午、申→酉、丑→辰→未→戌→丑） |
| 化退 | 同五行且地支逆退 |
| 化空 / 化墓 | 变爻逢空 / 入墓 |

**化进化退是启发式而非公理**（§3.7），五大边界条件（化进但入墓、旺极反衰、退即所愿、
用神不动、事成≠我好）由分析层逐条提示。

## 9. 本变五型（§3.12 / §3.13 统一命名）

本卦卦宫五行 → 变卦卦宫五行的关系，统一命名为**本变五型**：

| 关系 | 模型名 | 技术别名 | 导向 | 方式 |
|---|---|---|---|---|
| 本生变 | 主动顺推型 | 先生后 | 结果导向 | 主动 |
| 本克变 | 全程管控型 | 先克后 | 初始导向 | 管控 |
| 变生本 | 反哺受限型 | 后生先 | 初始导向 | 回馈 |
| 变克本 | 结果倒逼型 | 后克先 | 结果导向 | 强制 |
| 本比变 | 原状维持型 | 同类 | — | — |

**三条前提**：① 本卦＝始状态、变卦＝终状态（是**状态**不是结果）；② 卦级**不用来定成败**；
③ 比较基准＝**宫五行**。本变五型＝卦级；化进／化退／回头生克＝爻级，两者各管各的。

**属性面板与关系行对齐（v0.1.45）**：属性面板键值左对齐（键列贴面板左缘，整卦卡与半卦卡键列跨块同 x）；半卦块末尾三关系行（上下卦／世应／我事）改镜像三列轨道——标签列对齐键列（月旺衰／月长生／整旺衰等）、本侧值列对齐本侧面板「卦义」值字样、变侧值列对齐变侧面板「卦义」值字样。**本变旺衰趋势线（v0.1.46 口径，v0.1.47 长生链改版）**：五项旺衰/长生态值后挂趋势符号——**长生链两段方向**：上升段「胎→养→长生→沐浴→冠带→临官→帝旺」沿序 ↗ 逆序 ↘，下降段「衰→病→死→墓→绝」沿序 ↘ 逆序 ↗，跨段以所入段为准（帝旺→衰 ↘、绝→胎 ↗），同值 →；变卦侧同挂（v0.1.56）：整卦卡变卡与半卦卡变侧复用同一 trendArrs 数组，箭头与本侧同向、相同维同标 →——本卦看起点、变卦看终点。**五态旺衰**：本强变弱 ↘、本弱变强 ↗、持平 →；**线只挂本卦侧**（整卦本卦卡、半卦本侧面板），变卦侧不挂——线表示本卦的变化方向；卦义、日生克、无变卦不挂。**配色（v0.1.46）**：值色按旺衰——旺/相与长生至帝旺＝绿、休与胎养＝黑（默认）、囚/死与衰至绝＝红；线色 ↗绿、↘红、→黑。两字值（长生／帝旺／临官）整词不断行，箭头紧跟完整值后（v0.1.76 属性双列改弹性等分 minmax(0,1fr)——duo/cbz 侧栏挤压时不再顶破卡片边框，每列最窄容 4 字值「我生月令」≈80px；≤599px 回落单列 84px；v0.1.75 曾定宽 84px×2）。**得失分析半卦卡属性小字 5 行（v0.1.75，与整卦卡同键同位）**：前 4 行＝卦义｜日资源 / 月旺衰｜日旺衰 / 月长生｜日长生 / 月生克｜日生克，行5＝整旺衰｜空；KV_LAYOUT.hf＝[0,7,1,4,2,5,8,3,6,-1]，半卦五行对月日两令读数（structTokenArr 9 位不动、TREND_IDX 不含 7/8 不标箭头）。**两栏行防溢出（v0.1.76）**：duo（得失分析｜细项分析）与 cbz（整卦块｜成败面板）左右栏均等宽 1fr/1fr——半卡最小宽 ≈198px×2＋中列 130px＝526px，失窄列挤压即顶破；细项表本变列放开整体 nowrap（.c-ben/.c-bian normal，干支 gz2 保持整块），旺衰标签行 white-space:normal 窄列折行。

## 14. 六亲关系强弱四维度（§3.5）

`关系力度 = 施力方旺衰强弱 × 距离 × 动静 × 合冲`

| 维度 | 强 | 弱 |
|---|---|---|
| 施力方能量 | 旺且强 | 衰且弱 |
| 距离 | 相邻（爻位差 1） | 隔位 |
| 动静 | 动爻 | 静爻 |
| 合冲 | 有合或有冲 | 无合无冲 |

四维全强 → 决定性；三强 → 较强；两强 → 一般；≤1 → 微弱。

## 15. 虚实真假（v0.1.28，§19 真假维度）

- **虚实四态**（旺相 × 空破墓四象限，逐爻判定）：实／虚／半实半虚／半虚半实。
- **真假空**：旺相空＝**假空**（待出空填实）；休囚空＝**真空**。
- **合起合绊**：日合静爻 —— 旺相＝**合起**（激活），休囚＝**合绊**（牵制）。
- **真假前缀**：施力方空破墓或被日合绊时，其生克标「假」—— 看着有，实际无；
  比和同气不标。修正「空爻克财」被误读为真克的误读。
- **计权降级**：`relStrength` 对空破合绊施力方降级（−2，标注「作用不实」）。
